# Jeeva-Bindu 🩸

Jeeva-Bindu is a rapid blood response system designed to connect donors and seekers in real-time. This Android application leverages modern development practices and the Room database to provide a reliable platform for life-saving blood donations.

## Features

- **Dynamic Profile Management**: User profiles are linked to a local Room database, displaying donor details, blood group, and donation history.
- **Donation Tracker**: Automatic 90-day recovery tracker to monitor donor eligibility.
- **Emergency Requests**: Real-time blood requests with urgency levels and hospital locations.
- **Direct Communication**:
    - **Call Donor/Requester**: One-tap phone dialer integration.
    - **WhatsApp Alerts**: Prefilled emergency messages for instant response.
- **Impact Statistics**: Live tracking of available donors and emergency requests.
- **Donor Directory**: Searchable list of donors filtered by blood group and availability.
- **Responsive UI**: Built with Jetpack Compose for a modern and fluid user experience.

## Tech Stack

- **Kotlin**: Primary language for Android development.
- **Jetpack Compose**: Modern toolkit for building native UI.
- **Room Database**: Offline persistence for user profiles, requests, and donation history.
- **MVVM Architecture**: Clean separation of concerns for maintainability.
- **Coroutines & Flow**: Reactive and asynchronous data handling.
- **Navigation Compose**: Seamless screen transitions.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/jeeva-bindu.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle and run the app on an emulator or physical device.
